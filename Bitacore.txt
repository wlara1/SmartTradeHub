Points d’attention et dépannage rapide
•	Si vous recevez une erreur 500 liée à EF Core, vérifiez la chaîne de connexion dans appsettings.json et appliquez les migrations.
•	Commandes utiles (exécutées depuis la racine du repo) pour créer/appliquer les migrations (si nécessaire) :
•	Ajouter une migration :
•	dotnet ef migrations add InitialCreate --project SmartTradeHub.Infrastructure --startup-project API/SmartTradeHub.Api.csproj
•	Mettre à jour la base :
•	dotnet ef database update --project SmartTradeHub.Infrastructure --startup-project API/SmartTradeHub.Api.csproj
•	Si vous obtenez une erreur de liaison modèle, vérifiez les noms/typage des propriétés dans CreateOrderRequestDto (majuscules/minuscules, types GUID/decimal/int).
•	Les GUIDs customerId et productId doivent être valides.
